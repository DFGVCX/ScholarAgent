# PDF 公式恢复与视觉裁剪设计

## 背景

当前多模态 PDF 解析已经能识别公式、图、表格和算法，但真实双栏论文暴露了三类一致性问题：公式片段可能吸收同行正文且部分 Unicode 数学符号没有转为 LaTeX；图像裁剪依赖整页绘图对象并集，容易跨栏或吞入前一幅图；算法提取会把紧邻的长段正文纳入代码，同时前端懒加载会留下大块空白。

本次改动不删除旧解析器，也不改变论文、chunk 和检索的数据契约。它只提高 `multimodal-v3` 的结构恢复质量，并保留原始文本、原始截图和恢复来源，便于后续与旧切片方案比较召回率和准确率。

## 目标

- 公式块只合并同栏、同一公式行上的公式型片段，不吞入自然语言正文。
- 常用 Unicode 数学运算符稳定转换为 KaTeX 可渲染的标准 LaTeX。
- 每个公式块保存 `raw_text`、`latex`、`confidence` 和 `recovery_source`，前端始终能显示 LaTeX 原文用于调试。
- 图像裁剪以标题所在栏和相邻结构边界为约束，不再使用整页绘图对象并集。
- 图、表、算法截图在渲染后自动去除纯白边缘，同时保留少量安全边距。
- 算法遇到同栏长段自然语言时停止，不把后续正文当伪代码。
- 图表算法页面优先加载调试资产，避免卡片出现有高度但图片尚未加载的空白区域。

## 公式恢复

公式标签 `(n)` 仍是显示公式的锚点。候选片段必须同时满足：位于同一页、与标签属于同一栏、垂直方向与标签行相交或紧邻、文本长度受限，并且本身具有公式特征。长句、句号结尾的自然语言以及高字母词密度文本不加入公式组。

恢复阶段先清理无效控制字符，再把 `∇`、`‖`、`⊙`、`·`、`∗`、`×`、箭头及已有的求和、乘积、比较符号映射为 LaTeX 命令。专用恢复器仍优先处理已有的目标函数和加权求和；其余内容使用保守转换，不猜测缺失数学语义。

恢复结果既写入 manifest，也写入 `ParsedBlock.metadata`。正文渲染使用 `latex`，并在公式下方提供可展开或直接可见的 LaTeX 源码。低置信度结果明确标记恢复来源，方便人工对照 PDF。

## 图、表和算法裁剪

图的候选区域由标题栏决定。上边界优先取同栏上一条视觉标题的下边界；没有上一视觉标题时，取同栏最近的长正文或标题块下边界；仍不可用时回退到页眉安全边界。左右边界固定在标题对应的左栏、右栏或通栏范围，底边界包含当前标题。这样 Fig. 1 不会吞入左栏 Table I，Fig. 4 不会再次包含同栏较早的 Fig. 3。

表格保留现有单元格检测和横线检测逻辑，只增加最终的像素级去白边。算法继续以标题为起点收集同栏后续行，但在遇到新标题、过大间距、超出最大高度或长段自然语言时终止。

所有候选区域先按 200 DPI 渲染，再检测非白像素范围并增加固定像素边距。若图片几乎为空，则保留原始候选区域并把质量标记为 `review`，不静默丢失资产。

## 前端调试体验

图、表、算法资产使用 eager 加载，图片高度由真实宽高自然撑开。算法仍同时展示原始截图和提取出的代码块；公式同时展示 KaTeX 结果和 LaTeX 源码。任何渲染失败都回退到源码，不出现只有空白容器而没有可诊断信息的状态。

## 验收标准

- 合成双栏 PDF 中右栏图不会包含左栏表格或页眉。
- 同栏连续两幅图的后一幅裁剪不包含前一幅。
- 算法后的长段正文不出现在算法 markdown 或截图边界中。
- 公式块不包含相邻自然语言句子，常用 Unicode 数学符号已转换为 LaTeX。
- 真实联邦学习论文重新解析后，Fig. 1、Fig. 2、Fig. 4 和 Algorithm 1 的截图边界正确，公式调试信息完整。
- 旧解析器和旧切片代码保持可用，现有结构 API、RAG 接口和资产接口兼容。
