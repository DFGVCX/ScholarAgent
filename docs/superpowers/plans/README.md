# Historical implementation plans

This directory contains point-in-time implementation plans retained for design
history and traceability. Their checkboxes describe the intended execution
sequence at the time each plan was written; they are **not** the current project
status and are not maintained after the corresponding implementation diverges
or lands.

For the RAG subsystem, use [`RAG_TODO.md`](../../../RAG_TODO.md) as the single
source of truth for completed work, remaining work, blockers, and acceptance
criteria. Verify implementation claims against the current code, tests, and Git
history rather than inferring status from checkboxes in these historical files.
